# Team Memory（团队记忆）

- **版本**：v3.0（更新于 2026-11-27）
- **服务领域**：桥梁病害检测、无人机图像采集、交通工程（桥隧）AI 智能体与 3D 场景研发。
- **格式偏好**：
  - 严格适配 Obsidian Wiki 与 Typora 排版：顶部带 YAML frontmatter（`title`, `tags`, `created`, `updated`, `status`）。
  - 所有外部论文、规范、开源数据必须 1 对 1 附带**独立**深层可点击链接 `[标题](URL)`，优先引用交通运输部官网（`mot.gov.cn`）、arXiv、IEEE/ScienceDirect、GitHub、Zenodo 等一级来源，避免第三方转载资讯站。
  - 双链 `[[wikilinks]]` 必须来自仓库中真实存在的 `.md` 文件名（由确定性 Linter 硬校验）。
  - 每次入库需同步生成 `index.md` 与 `log.md` 的增量补丁草案，并在人工审批通过后由 `finalize_and_log` 自动写入词条并合并索引与日志。
- **规范口径**：
  - 公路桥梁技术状况评定以 2026 年 11 月 1 日施行的《公路桥梁技术状况评定标准》（JTG/T 5230—2026，废止原 JTG/T H21—2011）及 2026 年 2 月交通运输部《低空无人机应用公路桥梁巡检技术指南（试行）》（交办公路〔2026〕8 号）为现行基准。
- **高频避坑清单**：
  - 不使用空洞占位符（如 `[待补充]`、`TBD`）。
  - 必须显式给出工程落地边界（边缘延迟/算力、像素定性 vs 毫米级标定定量、规范合规与现场人工校核）。
  - Synthesizer 写入暂存文件后不再在 JSON 中重复粘贴全文，减少无效输出耗时。
- **当前提示词版本**：`Lead v3` / `WebScout v3` / `VaultMiner v2` / `Synthesizer v2` / `Checker v2`
